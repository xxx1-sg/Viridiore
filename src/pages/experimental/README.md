# 已下架模块

这些页面在 v2.0 的"做减法"里从产品界面移除了。代码保留，但没有被 `src/main.js` 引用，
不参与打包——留着是为了以后需要时能取回算法与交互，而不是因为它们还能用。

| 模块 | 下架原因 |
| --- | --- |
| `sos.js` | 没有真实求救通道（无短信网关、无卫星通信）。假 SOS 比没有 SOS 更危险。 |
| `teammate.js` | 队友位置只有前端壳，没有任何同步后端。 |
| `pressure.js` | 曲线由随机数合成，不是设备气压计读数。 |
| `gear.js` | 装备清单没有差异化，属于"能用但不必自己做"。 |
| `roadbook.js` | 路线点赞数是写死的；等有了后端存储与叙事层再做。 |
| `ai.js` | 关键词匹配伪装成 AI，第一次使用就会让用户失望。已改为三层的 `services/intent.js` / `chase.js` / `narrative.js`。 |
| `alert.js` | 预警本身是真的（来自和风），已并入天气页的横幅，不再单独占一个页面。 |
